Glowbeat Party Mode, five ways

The same macOS panel, same controls, same copy. Only the design system changes.

01 · MiniDisc UI

MiniDisc UI Design System. Sony-hardware chassis: brushed metal, chrome strip, green phosphor LCD wells, pad-printed silver labels, segmented VU meter.

Open full size

02 · PW-SEQ-1

PW-SEQ-1 Design System. Molded sequencer cabinet: orange accent, step buttons with LEDs, ticked slider tracks, boxed VT323 readouts, Space Mono chrome with sentence-case help text.

Open full size

03 · Hybrid

Hybrid. MiniDisc shell, printed labels, metal hardware and segmented VU meter. PW-SEQ-1 orange accent, step-button picker, ticked tracks, phosphor readout chips, Space Mono chrome and sentence-case help text. Shown with "Always react" checked, so the threshold is grayed out.

Open full size

04 · Glowbeat

Glowbeat Design System. MiniDisc chassis, chrome strips and segmented meter. PW-SEQ-1 single-accent discipline, step buttons and ticked tracks. Liquid Glass sheets, native SwiftUI controls, SF Pro. Every dot removed: indicators are bars, underlines and edge glows.

Open full size

05 · Minimal 2026

Minimal 2026. The opposite of the hardware mockups: SF Pro only, a quiet neutral panel, one lamp-amber accent, one Liquid Glass sheet carrying Trigger Level, concentric radii and layered shadows in place of borders. Dark and light are both first class.

Open full size
Every file is self-contained: fonts embedded as data URIs, no external stylesheets or scripts. Mockups 01, 02, 04 and 05 show "Always react" unchecked; mockup 03 shows it checked so both states are visible across the set.
