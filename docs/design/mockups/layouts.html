Glowbeat main window, three layouts

Each frame is the real 1000 by 760 content area, at full size. If a layout needed to scroll on the common path, you would see it inside its own frame.

One at a time
A

One driver

Fits at 1000 x 760 1000 x 760 frame

Optimizes the first question the window has to answer: which of the three things is driving the bulbs. One control answers it, so both on/off toggles and the caption about only one running at a time disappear.

Costs width. The driver panel is 602 px, so the palette shrinks to a 5 by 2 grid and the captions become hover help, and opening Advanced runs 72 px past the window.

Common path fits without scrolling. Measured at 1000 x 760: the left column uses 636 of 658 px and the driver panel fills its 658 px with the Reset row anchored at the foot. Opening Advanced needs 730.

B

Sidebar

Fits at 1000 x 760 1000 x 760 frame

Optimizes headroom. The Party pane gets the whole window, so nothing is abbreviated: Advanced expanded, captions still prose, full size chips, and the strip keeps all six bulbs one click away from every pane.

Costs a sidebar for four items and a second home for the bulbs. Party and Scenes now sit two rows apart, so the fact that only one of them runs is less obvious.

Common path fits without scrolling, and so does every other pane with every disclosure open. Measured at 1000 x 760: the Party pane uses 622 of 624 px, and no pane overflows.

C

Compact stack

Fits at 1000 x 760 1000 x 760 frame

Optimizes familiarity. Still the single column you have today, just squeezed: six bulb tiles, Schedule folded into one summary line, Scenes and Party merged under one Driver control so only one panel is ever on screen.

Costs all of its slack. There are 28 px left at the bottom, so expanding Schedule (84 px) or Advanced (106 px) overflows the window straight away.

Common path fits without scrolling. Measured at 1000 x 760: the stack uses 664 of 686 px. Schedule open needs 770, Advanced open needs 792, both open need 914.
