# Want to help?

Thanks for stopping by. Here's how to pitch in.

## The most useful thing: try other Govee lights

I've only tested Glowbeat with one kind of bulb: the 6 pack from Costco (Govee H6004). If you have a different Govee light, try it and tell me what happened. [Open an issue](https://github.com/fomoPhil/glowbeat/issues/new) with:

- The model (it's in the Govee Home app, under the device's settings)
- Whether Glowbeat found it
- What worked and what didn't: on/off, brightness, colors, Party

"It worked" is just as useful as "it didn't."

## Found a bug?

Open an issue. Tell me what you did, what you expected, and what happened instead. A screenshot helps a lot.

## Code

Pull requests are welcome. A few ground rules keep the app nice to use:

- Build with `xcodegen generate`, then the Glowbeat scheme in Xcode (macOS 14.4 or later).
- Keep the build at zero warnings, and run the tests before you open the PR.
- Add a test for anything you fix or change.
- For anything big, open an issue first so we can talk it through.

Be kind. That's the whole code of conduct.
